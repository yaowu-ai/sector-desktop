# 平台自动登录 V1 Tasks

## M1 配置模型

- [ ] 在账号配置 schema 中增加 `login` 字段。
- [ ] 支持 `login.enabled`。
- [ ] 支持 `login.method`，V1 默认为 `password`。
- [ ] 支持 `login.username`。
- [ ] 支持 `login.credential_ref`。
- [ ] 缺少 `login` 时默认视为关闭自动登录。
- [ ] 配置保存和备份确认不包含密码明文。
- [ ] 配置校验：自动登录开启时必须有 username。
- [ ] 配置校验：自动登录开启时必须有可用 credential_ref 或待保存密码。

## M2 凭据存储

- [ ] 调研并选择 Windows Credential Manager 或 DPAPI 方案。
- [ ] 实现保存账号密码。
- [ ] 实现删除账号密码。
- [ ] 实现检查账号密码是否存在。
- [ ] 实现读取账号密码供任务启动使用。
- [ ] 前端保存成功后清空密码输入状态。
- [ ] 后端日志不输出密码。
- [ ] 诊断导出时不包含密码。

## M3 账号管理 UI

- [ ] 账号新增表单增加登录信息区块。
- [ ] 账号编辑表单增加登录信息区块。
- [ ] 增加自动登录开关。
- [ ] 增加登录账号输入框。
- [ ] 增加密码输入框，仅用于保存或更新。
- [ ] 显示凭据状态：未保存 / 已保存 / 读取失败。
- [ ] 增加保存密码按钮。
- [ ] 增加删除密码按钮。
- [ ] 增加检测登录状态按钮。
- [ ] 增加测试自动登录按钮，并要求二次确认。

## M6 Runtime 集成

- [ ] Tauri 启动 runtime 时按账号注入临时登录环境变量。
- [ ] 密码不通过命令行参数传递。
- [ ] runtime 读取登录环境变量。
- [ ] runtime 不打印登录密码。
- [ ] 多账号队列中每个账号只拿到自己的密码。
- [ ] 自动登录成功后继续执行原养号任务。
- [ ] 自动登录失败时不继续执行点赞、关注、评论等动作。

## M7 人工接管

- [ ] runtime 输出 `AM_AUTH_EVENT` 结构化事件。
- [ ] Tauri 解析人工接管事件。
- [ ] 任务状态支持 `intervention_required`。
- [ ] UI 显示需要人工处理的账号和原因。
- [ ] 保持浏览器窗口打开。
- [ ] 增加“我已完成，继续检测”按钮。
- [ ] 增加“跳过当前账号”按钮。
- [ ] 增加“停止任务”按钮。
- [ ] 用户完成验证后可重新检测登录状态。
- [ ] 检测已登录后继续原任务。

## M8 诊断与日志

- [ ] 诊断页支持检测指定账号登录状态。
- [ ] 诊断页支持测试自动登录，并要求二次确认。
- [ ] 诊断页显示最近登录错误。
- [ ] 任务日志记录登录流程状态。
- [ ] 日志脱敏密码和凭据。
- [ ] 支持删除账号保存的凭据。
- [ ] 支持复制登录错误详情，且不包含密码。

## M9 测试与验收

- [ ] 旧账号配置不包含 `login` 时仍可运行已登录 profile。
- [ ] 自动登录关闭时不输入账号密码。
- [ ] 自动登录开启但缺少密码时阻止启动并提示。
- [ ] 已登录 profile 能跳过登录直接运行任务。
- [ ] 未登录 profile 能进入自动登录流程。
- [ ] 登录成功后继续养号任务。
- [ ] 验证码场景进入人工接管。
- [ ] 二次验证场景进入人工接管。
- [ ] 密码不出现在 `accounts.yaml`。
- [ ] 密码不出现在配置备份。
- [ ] 密码不出现在命令行参数。
- [ ] 密码不出现在 stdout、stderr 或 sessions.log。

## 建议实施顺序

1. 先做配置模型和账号管理 UI，但不接入自动登录。
2. 接入本机安全凭据存储。
3. 抽象 AuthAdapter，并在任务启动前插入 `ensure_logged_in`。
4. 实现 TikTok 登录状态检测。
5. 实现 TikTok 自动填写账号密码。
6. 实现人工接管事件和 UI。
7. 做完整脱敏和干净环境验收。
